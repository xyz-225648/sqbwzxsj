# 特殊日表（作息模板覆盖）—— 维护入口就是本文件，改它不用改页面、不用发版。
# 生效优先级：设置里的「今天按…」下拉（本机手动覆盖） > 本文件 > 星期规则（周六/周日/工作日）
#
# 格式：每行一条，支持日期区间，# 开头是整行注释，行尾也能写 # 注释
#   YYYY-MM-DD            模板名  说明
#   YYYY-MM-DD~YYYY-MM-DD 模板名  说明
# 模板名：weekday 周内作息 / saturday 周六（半天课）/ sunday 周日 / holiday 放假（全天休息）
#
# 维护时机：每学年开学前，把校历里的法定节假日、寒暑假、调休补课日填进来（约 20~30 行）。
# 临时调整（当天停课、提前放假）：加一行即可，用户下次打开就生效；
# 用户也可以在「设置 → 今天按哪套作息」里自己一键切，不必等这里更新。
#
# 下面几行是示例，默认全部注释掉，需要时去掉开头的 # 即可：
# 2026-10-01 holiday 国庆
# 2026-10-01~2026-10-07 holiday 国庆假期
# 2026-10-10 weekday 调休补课（按工作日作息）
# 2026-01-20~2026-02-25 holiday 寒假
