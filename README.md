# 宿迁职业技术学院作息时间表

四个专业方向（信息设计 / 信息基础 / 通识教育 / 女子教育）的一日作息时间轴，
电脑、安卓手机、浏览器三端通用。

## 下载使用

| 平台 | 文件 | 说明 |
|---|---|---|
| **Windows** | 宿迁职业技术学院作息时间表.exe | 双击即用，免安装（需系统带 WebView2，Win11 自带） |
| **安卓手机** | 宿迁职业技术学院作息时间表.apk | 允许「安装未知来源应用」后安装 |
| **浏览器** | index.html | 任意浏览器直接打开 |

手机浏览器打开 index.html 也能正常使用（竖排时间轴）。

## 功能

- 全天时间轴，**横版 / 竖版**自动切换（窗口变窄自动立起来）
- **当前时间高亮** + 「还有几分钟下课 / 还有几分钟上课」倒计时
- 点按时间轴任意位置可**钉住**该时刻，查看四个方向当时的状态
- 电脑版另有平滑回顶按钮
- **完全离线可用**

## 自动更新

软件启动时会自动检查本仓库里的 index.html，发现新版本就静默替换。
所以**改课表只需上传新的 index.html 和 version.txt**，所有人下次打开就是最新的，
不用重新安装。

## 文件说明

| 文件 | 用途 |
|---|---|
| index.html | 网页主体（也是自动更新的内容源） |
| version.txt | 版本标记，内容变了才触发更新 |
| app.py | Windows 端源码（pywebview） |
| publish.sh | 一键发布脚本：生成 index.html + version.txt |
| set-update-url.sh | 设置更新地址并重新打包 |

详细说明见 自动更新使用说明.md
