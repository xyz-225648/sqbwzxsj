

# 宿迁职业技术学院作息时间表

## 项目概述

宿迁职业技术学院作息时间表是一款专为四个学院（信息设计学院、信息基础学院、通识教育学院、女子教育学院）设计的多平台课程时间表应用。本项目采用一次开发、多端部署的理念，通过统一的 HTML 核心页面配合平台特定的外壳程序，实现 Windows 桌面版、安卓手机版和浏览器网页版的全平台覆盖。

当前版本：**v2.0.1**

## 核心特性

本应用在设计上遵循「简洁实用、离线优先」的理念，所有功能都围绕提升师生查看课表的体验而展开。横竖版自动切换确保在任意设备上都能获得最佳浏览效果，当前时段高亮配合倒计时功能让师生能够精准掌握上下课时间。完全离线可用的设计意味着应用不依赖任何外部服务，校徽图标等资源全部内嵌，即使在网络完全中断的环境下也能正常使用。

桌面版在网页基础上增加了多项实用功能：窗口置顶功能允许用户将课表窗口固定在屏幕最前方，方便随时查看；关闭到托盘设计让应用在后台静默运行，课表提醒照常触发；单实例机制确保重复启动不会创建多个窗口；Windows 系统通知集成则让用户无需打开窗口即可获取重要的上下课提醒。手机版则针对移动设备进行了专门优化，走系统通知通道确保提醒的及时性和可靠性，首次启动时申请通知权限，打开后自动从仓库拉取最新课表数据。

## 快速开始

### 下载安装

前往 [发行版页面](https://gitee.com/xyz-225648/sqbwzxsj/releases) 下载对应平台的安装文件。Windows 用户下载 `宿迁职业技术学院作息时间表.exe`，双击即可运行，无需安装（需要 WebView2 运行环境，Windows 11 已自带）。安卓用户下载 `宿迁职业技术学院作息时间表.apk`，在手机设置中开启「安装未知来源应用」权限后即可安装。浏览器用户可直接打开仓库根目录的 `index.html` 文件，无需任何服务器环境。

### 使用说明

应用启动后会显示当日的完整作息时间轴，横版模式下四个学院的时间条并列展示，竖版模式下则纵向排列。窗口宽度变化时会自动切换横竖版布局，手机设备默认使用竖版。当前时段会有高亮显示，并实时倒计时显示「还有几分钟下课」或「还有几分钟上课」。将鼠标悬停在任意时刻可以预览该时段的具体安排，点击该时刻可以「钉住」查看四个学院当时的状态。点击学院名称可直接跳转到下方对应的详情卡片，桌面版界面还提供「回到顶部」按钮和 Ctrl + 滚轮缩放功能，缩放比例会被自动记住。

设置面板位于界面右上角，提供按学院分别开关通知、下课前提醒（可自定义提前分钟数）、上课前提醒和下课时提醒等功能。所有设置改动即时生效并自动保存，关闭窗口后下次打开仍然保持上次的设置。设置面板还提供测试通知功能，可用于验证通知通道是否正常工作。

### 桌面版特有功能

桌面版（Windows）额外提供窗口置顶功能，可通过页头按钮或快捷键 Ctrl + T 切换，也可在设置面板中开关。关闭窗口时点击 ✕ 按钮只会隐藏窗口到系统托盘，课表提醒继续在后台运行；双击托盘图标即可恢复窗口显示。应用采用单实例设计，重复双击 exe 不会创建新窗口，而是将已存在的窗口（包括托盘中的实例）带到前台。Windows 系统通知集成支持校徽图标展示，可在系统设置的「系统 → 通知」中管理。

### 手机版特有功能

安卓版走系统通知通道，首次启动时会申请通知权限。应用打开后会后台自动检查并更新为仓库中的最新课表，通常 1-2 秒即可完成刷新。手机版不显示「置顶」和「切换横竖版」等仅对桌面端有意义的按钮，界面针对触屏操作进行了优化。

## 项目结构

### 核心文件

| 文件 | 说明 |
|------|------|
| `index.html` | 网页主体文件，也是自动更新的内容来源。日常开发时页面源码名为 `宿迁职业技术学院作息时间表.html`，发布脚本 `publish.sh` 会将其复制为 `index.html`。仓库中只保留一份副本，避免重复维护 |
| `version.txt` | 版本标记文件，内容变化时触发自动更新机制 |
| `app.py` | Windows 桌面版源码，基于 pywebview 和 WebView2 构建，提供窗口管理、系统托盘、通知等原生功能 |
| `publish.sh` | 一键发布脚本，执行自检、生成 release 目录中的 Windows exe 和安卓 apk 文件 |
| `check_live.py` | 发布后核验脚本，验证线上网页、版本号和下载链接与本地是否一致 |

### 测试与质量保障

| 脚本 | 功能说明 |
|------|----------|
| `check_page.py` | 页面内联脚本语法检查，使用 Node.js 的 `--check` 参数进行静态分析 |
| `smoke_page.py` | 无头浏览器渲染冒烟测试，覆盖三档视口尺寸和安卓 User-Agent，检测未捕获异常和渲染缺失 |
| `functest_page.py` | 无头浏览器结合 Chrome DevTools Protocol 的交互遍历测试，验证悬停、钉住、设置保存、通知判定、更新弹窗、缩放、防调试等全部交互功能 |
| `selftest_api.py` | 桌面版本地接口自检，覆盖 `/ping`、`/state`、`/notify`、`/latest`、`/quit` 五个 API 端点 |
| `functest_app.py` | 桌面外壳端到端测试，验证单实例机制、系统托盘、窗口置顶、正常退出等原生功能。可测试源码状态或已打包的 exe 文件 |
| `check_live.py` | 发布后核验工具，确保线上资源与本地一致 |

执行测试的方式非常简单：运行 `python functest_app.py` 测试源码状态，或附加 `--exe` 参数测试打包后的 exe 文件。

## 技术架构

### 前端架构

页面采用原生 HTML/CSS/JS 实现，不依赖任何外部框架，确保体积小巧和完全离线可用。DOM 结构分为页面主体、时间轴（支持横竖版切换）、详情卡片三个主要层级。时间轴模块（gantt）负责展示全天时间线，竖排模块（vt）提供竖屏适配，两者根据视口尺寸自动切换。卡片模块（cards）展示四个学院的详细信息，支持点击学院名快速定位。

### 桌面版架构

Windows 桌面版基于 pywebview 构建，将 HTML 页面封装为原生窗口。`app.py` 实现了以下核心功能：窗口管理（包括显示、隐藏、置顶、大小调整）、系统托盘集成、API 服务器（提供应用与页面间的通信通道）、自动更新检查与静默安装、Windows 系统通知发送、配置文件读写（窗口状态、用户设置等）。WebView2 作为渲染引擎，确保页面渲染效果与 Edge 浏览器一致。

### 自动更新机制

应用启动时首先秒开本地版本，保证用户无需等待即可使用。随后后台向码云发起版本检查请求，通过比对 `version.txt` 内容判断是否有新版本。若有新版本则自动下载并静默替换本地页面，用户下次启动时即可使用新版本。开发者只需修改 `index.html` 和 `version.txt` 即可推送更新，无需重新发布 exe 或 apk。只有当需要更新外壳程序时，才需要创建新版本并替换发行版附件。

### 版本号规范

版本号采用 `V主.次.补丁` 三段式格式。主版本号在架构改动、重大功能新增或重构时递增（如 V1 → V2）；次版本号在新增普通功能或界面优化时递增（如 V2.0 → V2.1）；补丁号仅用于 Bug 修复和微小调整，不新增功能（如 V2.0.0 → V2.0.1）。页面中的 `APP_VERSION` 变量、`version.txt` 文件和安卓 `versionName` 必须保持一致，发布脚本会自动从页面读取版本号写入 `version.txt`，确保不会产生版本不一致的问题。
